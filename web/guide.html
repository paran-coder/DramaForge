DRAMAFORGE / HOW TO USE

작가의 결정을 지키면서,
이야기를 완성하는 방법

AI와 함께 기획하되 확정된 설정은 작가만 승인합니다. 처음 사용하시는 분은 작품 시작부터, 기존 사용자는 필요한 기능부터 확인하세요.

01 / START

AI와 새 작품 기획하기

새 작품을 만들면 시작 방법을 선택할 수 있습니다. AI와 새 작품 기획을 고르면 인터뷰형 질문 또는 자유 대화로 설정을 구체화합니다.

  1. 작품 보관함의 ＋ 버튼을 눌러 새 작품을 만듭니다.
  2. AI와 새 작품 기획을 선택합니다.
  3. 기획 대화 입력창에 소재, 장르, 구상 중인 갈등을 입력합니다.
  4. AI 기획 검토 · 답변을 실행합니다. AI 연결이 필요합니다.
  5. 마음에 드는 결정은 정설·결정 관리에서 검토 후 직접 승인합니다.

대화에서 “좋아”라고 말해도 정설이 자동으로 바뀌지는 않습니다.

02 / IMPORT

기존 기획서·줄거리·대본 가져오기

기존 기획으로 시작할 때는 기존 기획 가져오기를 선택하고 여러 파일을 함께 넣을 수 있습니다.

  1. TXT, MD, JSON 텍스트 파일을 선택합니다. 각 파일 16만 자 이하, 최대 12개입니다.
  2. 기획 대화에서 기존 자료를 비교·검토하도록 요청합니다. 자료가 길면 모든 본문이 아닌 각 파일의 일부 발췌를 AI에 전달하므로 중요한 구간은 대화에 추가로 지정하세요.
  3. 충돌이나 누락이 있으면 근거를 확인하고 작가가 직접 수정 여부를 결정합니다.

PDF/DOCX 직접 읽기는 아직 지원하지 않습니다. 내용을 TXT/MD로 변환하세요. 가져온 자료는 정설이 아닌 참고 자료입니다.

03 / CONNECT

ChatGPT Codex 연결

AI 요청은 사용자 PC에서 실행 중인 Codex CLI로 전달됩니다. Vercel 서버가 대본을 받아 저장하지 않습니다.

  1. 웹앱의 AI 연결을 누르면 기존 로컬 연결 프로그램을 자동으로 찾아 연결을 시도합니다.
  2. 이미 설치·실행 중이라면 별도 연결코드가 필요하지 않습니다.
  3. 처음 사용할 때는 연결 도우미 파일을 내려받아 설치·실행해야 합니다. Node.js 20 이상과 Codex CLI가 필요합니다.
  4. Windows에서는 run-windows.cmd, macOS/Linux에서는 run-unix.sh를 실행합니다. 앱에서 웹 주소를 입력할 필요는 없습니다.
  5. 다시 자동 연결을 누르고 ChatGPT 계정 로그인이 필요하면 공식 인증을 완료합니다.

보안 안내: 브라우저는 로컬 프로그램을 사용자 동의 없이 자동 설치할 수 없습니다. 프로그램 설치와 OS 보안 승인 절차는 생략할 수 없습니다. 연결 프로그램은 루프백 주소에서만 동작하며 지정된 DramaForge 주소만 허용합니다.

04 / CANON

정설과 변경 이력 관리

AI가 제안한 캐릭터, 사건, 기획 원칙은 모두 후보로 시작합니다. 작가가 승인한 정보만 정설로 적용합니다. 기각·보류 이유도 남아 재논의를 줄입니다.

  1. 정설 · 결정 관리에서 후보를 등록하거나 AI의 제안 후보를 확인합니다.
  2. 관련 원문과 기존 결정을 대조합니다.
  3. 승인·보류·기각을 선택합니다.
  4. 확정 설정의 수정은 별도 변경 요청으로 처리하고 영향받는 샷을 재검증합니다.
05 / EPISODES

회차별 대본과 연속성 검증

전체 줄거리를 먼저 작성한 뒤 회차를 나누거나, 바로 회차부터 시작할 수도 있습니다. 사건의 원인·결과, 인물이 아는 정보, 관객 공개 시점과 복선을 기록합니다.

확정 정설과 직접 충돌하는 샷은 최종 승인을 차단합니다. 해석상 의심은 경고로 표시하며 작가가 판정합니다.

06 / PRODUCTION

스토리보드와 Seedance 프롬프트

영상 제작 탭에서 대본을 샷으로 분할하고, 스토리보드 이미지를 생성·등록한 뒤 검수합니다. 승인된 샷만 최종 Seedance 프롬프트로 내보낼 수 있습니다.

영상 생성은 외부 Seedance 서비스에서 진행하고 결과 파일은 필요에 따라 로컬에서 연결합니다.

07 / LOCAL FIRST

저장·백업·데이터 처리

작품과 승인 정보는 현재 브라우저의 IndexedDB에 저장됩니다. ZIP 백업을 주기적으로 내려받아 보관하시기 바랍니다. 브라우저 저장 기록을 지우면 백업 없이 복원할 수 없습니다.

AI 요청 시 사용자가 제공한 대본과 참조 자료는 Codex를 통해 OpenAI로 전달될 수 있으며, 외부 영상 제작 서비스에 전달한 자산은 해당 서비스의 처리 조건을 따릅니다. Vercel Analytics는 페이지 방문 통계를 수집할 수 있지만 작품 내용을 별도 이벤트로 전송하도록 만들지 않았습니다.
