# UI Polish 검토 — DramaForge v1.5.1

## 1. 대상과 보호 범위

- **요청 영역:** 앱 전체의 텍스트 계층, 색상, 표면 대비, 기본 버튼/폼 상태 및 모바일 읽기 편의
- **사용한 기준:** 사용자가 첨부한 `ui-polish` v2.0.0의 `REFINE` 규칙, `DESIGN-binance`의 색상·타이포·간격 토큰
- **보호한 영역:** 대본 입력/AI 기획 대화, 정설 승인/기각, 회차·샷 상태 전이, 로컬 브리지 요청, IndexedDB·ZIP, 이벤트 대상 ID, CSP 및 Vercel 구성
- **적용 범위:** `web/theme.css` 신규, `web/index.html`에서 스타일 링크/버전/테마색 변경, `package.json` 패치 버전, UI 테스트 추가. JS 비즈니스 로직 변경 없음.

## 2. 관찰된 문제 (v1.5.0)

- 주요 패널 제목이 16px인데 주변 버튼과 캡션은 10–12px여서 정보 위계가 약함.
- 대본 편집기 본문 13px로 긴 한국어 문장의 읽기 피로가 큼.
- 상호작용 요소들이 골드, 남색, 회색 등 여러 개의 색 규칙으로 구성되어 주요 행동을 즉시 찾기 어려움.
- 본문 보조 설명 중 10px가 반복되어 정보가 지나치게 작게 보임.

## 3. 적용한 디자인 계약

| 역할 | 전(계산 스타일) | 후(계산 스타일) | 비고 |
|---|---:|---:|---|
| 페이지 제목 | 27px | 26px | 강조 굵기 700과 명확한 보조 설명 |
| 패널 제목 | 16px | 18px | 영역 식별력 증가 |
| 대본 편집 | 13px | 15px | 긴 문장 가독성 향상 |
| 일반 본문 | 요소별 불일치 | 14px 중심 | 버튼·검토 카드·입력 일관화 |
| 보조/메타 | 최소 10px | 12–13px 중심 | 대화 출처·정설 상태 가독성 보강 |
| 기본 강조 | 금빛 #d7a05e | 노랑 #fcd535 | 노랑은 주요 CTA 및 활성 탭에 집중 |

### 사용한 컬러 토큰

- 배경 `#0b0e11` / 패널 `#1e2329` / 상승 표면 `#2b3139`
- 주요 버튼 `#fcd535`, 클릭 강조 `#f0b90b`, 버튼 글자 `#181a20`
- 본문 `#eaecef`, 보조 `#adb5bf`, 메타 `#929aa5`
- 포커스 `#3b82f6`, 위험 `#f6465d`, 성공 `#0ecb81`

상용 전용 폰트(`BinanceNova`, `BinancePlex`)는 포함하지 않고 로컬에 있는 Inter·Pretendard 및 시스템 폴백을 사용합니다. 해당 서비스의 로고·브랜드 요소도 재사용하지 않습니다.

## 4. 접근성·성능 관점

- WCAG 대비 계산(정적 토큰): 노랑 버튼 대 검정 글자 **12.18:1**, 본문 대 패널 **13.36:1**, 보조 문구 대 패널 **7.64:1**, 메타 문구 대 배경 **6.81:1**. 이는 **해당 색상 쌍의 대비 평가**이지 전체 WCAG 적합성 인증은 아닙니다.
- 키보드 `:focus-visible`에 2px 파란 테두리 제공, 최소 버튼 높이 일반 40px/작은 버튼 36px.
- 기존 reduced-motion 분기를 유지하고 새 버튼 전환도 해제.
- 그라데이션, 그림자 추가 없이 배경 계층과 테두리로 깊이 구분.
- 정적 렌더링(1440/390px)에서 가로 오버플로 없음, JS 오류 0건.

## 6. 회귀 위험과 후속 검증

글자 크기가 커져 카드 높이가 늘고, 긴 승인 기록은 이전보다 줄바꿈이 많아질 수 있습니다. 실제 배포 전에 대용량 정설 목록, 긴 프롬프트, 200% 브라우저 확대, 모바일 환경의 터치 접근성과 대화 팝업을 확인해야 합니다.

## v1.6.0 추가 UI 점검 (범위 한정)

- 기존 v1.5.1의 검정/회색/노랑 디자인 토큰과 26/18/16/14/12px 위계를 변경하지 않았습니다.
- 신규 `narrative-grid`만 추가하고, 승인/반전/시간축을 분리한 두 패널을 회차 관리 탭 하단에 구성했습니다.
- `--color-primary`는 후보 등록 CTA에만 쓰고 중요/치명 경고는 각각 `--color-warning` 및 `--color-danger`를 사용합니다.
- Chromium `page.set_content()` 격리 환경에서 1440px 2열, 390px 1열, 가로 넘침 없음, 패널 제목 18px 및 CTA RGB(252,213,53) 확인했습니다.
- 전체 앱 URL로 접근, 실사용 IndexedDB, 스크린리더 및 정설 플로우 E2E는 별도 실사용 검증 대상입니다.
