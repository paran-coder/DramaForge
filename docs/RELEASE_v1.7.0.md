# DramaForge v1.7.0 — 기능 변경 및 배포 안내

## 변경 범위 (승인된 기획)
1. 새 작품 시작 화면: AI와 공동 기획(인터뷰형/자유 대화형)과 기존 기획 가져오기를 구분합니다. 전체 줄거리 후 회차로 발전시키는 기존 흐름을 유지합니다.
2. TXT/MD/JSON 여러 파일을 승인되지 않은 참고 문서로 저장하며, 이름·일부 내용을 기획 검토 Codex 프롬프트에 첨부합니다. 이전 정설은 전혀 변경하지 않습니다. 문서의 전체 분량을 AI가 항상 읽는 것은 아닙니다. 각 파일의 발췌 범위 안에서 검토하고 필요한 구간은 작가가 추가로 제공해야 합니다.
3. `/guide.html` 사용자 안내를 추가했습니다. 데스크톱/모바일 헤더의 사용방법 링크에서 접근합니다.
4. AI 연결 화면에서 수동 페어링 코드 입력을 제거했습니다. 브리지는 `POST /api/connect`를 지원하고, `--origin`으로 명시적으로 허용된 웹사이트의 JS에만 임시 Bearer 토큰을 내줍니다. 로그인/AI 작업은 이후 모든 요청에서 Bearer 검증을 합니다.
5. 연결 도우미 v1.7.0의 실행 스크립트는 운영 URL `https://dramaforge-lemon-ten.vercel.app`을 고정하여 별도 웹 주소 수동 입력이 필요 없습니다.

## 구현과 기술적 제약
브라우저는 네이티브 실행 파일을 사용자 동의 없이 설치할 수 없습니다. 이번 릴리스는 **이미 설치되어 실행 중인 도우미 자동 연결**까지만 구현합니다. 처음 쓰는 사용자는 도우미 아카이브를 직접 받고 실행해야 합니다. ZIP은 서명된 설치 프로그램이 아닙니다. 완전 무인 설치, 자동 실행 및 OS별 서명·패키지 설치는 구현·검증되지 않았습니다.

## 공개 사이트 보안
- 브리지는 127.0.0.1:7331에만 바인딩합니다.
- `Host`와 정확한 `Origin`을 확인합니다.
- AI 작업, 로그인, 상태 조회는 인메모리 Bearer 토큰으로 보호합니다.
- 임의 OS 명령 모드가 없는 AI 작업 allowlist를 유지합니다.
- 정설·변경 승인 권한은 오직 작가에게 유지됩니다.
- 사용자 프로젝트는 브라우저 IndexedDB와 ZIP 백업에 저장되며 Vercel 데이터베이스는 없습니다.
- Codex로 보낸 내용은 OpenAI에 전달될 수 있습니다. Vercel 방문 통계는 Web Analytics 설정에 따릅니다.
- `/api/pair`는 이전 클라이언트 호환을 위해 서버에 남아 있지만 웹 UI는 사용하지 않습니다.

## 로컬 실행
```bash
npm run check
npm run build
npm run dev
```
`npm run dev`로 정적 웹 페이지를 미리볼 수 있습니다. **실제 AI**를 사용하려면 PC에 Node.js 20+, Codex CLI 및 실행 중인 도우미가 필요합니다. 도우미는 `connector-package` 또는 배포된 `web/downloads/DramaForge-Connector-v1.7.0.zip`에 포함합니다.

## Vercel 배포
아직 GitHub `main`이나 Vercel 운영에 반영하지 않았습니다. Preview에 소스를 배포해 기존 작품 ZIP 복원, 실제 브라우저 IndexedDB 저장·새로고침, ChatGPT 로그인, 로컬 Origin/CORS 허용, 신규 시작 방식과 사용방법 페이지 링크를 점검한 뒤 운영 반영을 승인받는 것이 필요합니다.

## 유지된 외부 공유 설정
OG 이미지와 운영 정규 URL은 기존 `/og-image.png`, `https://dramaforge-lemon-ten.vercel.app/`을 계속 사용합니다. Analytics 코드는 기존 정적 사이트 스크립트를 유지합니다.
