# DramaForge v1.7.2 — 연결 도우미 설치/로그인 수정

## 보고된 증상

- Windows 연결 도우미를 내려받아 실행했지만 웹 UI의 연결 상태가 변하지 않음.
- `ChatGPT 로그인`을 눌러도 로그인 창이 열리지 않음.
- UI에는 “브리지에 연결할 수 없습니다. 실행 상태와 허용 웹 주소를 확인하세요.”라는 메시지가 표시됨.

## 소스 수준에서 확인된 원인

1. **원본 Windows CMD의 구분자 검색 오류**: `IndexOf('### DRAMAFORGE-POWERSHELL ###')`는 PowerShell 실행 명령문 내부에 포함된 첫 구분자를 찾아 설치 스크립트 대신 CMD 명령문의 나머지를 PowerShell로 전달할 수 있었습니다. `LastIndexOf`로 마지막 구분자를 찾도록 수정했습니다.
2. **실행 성공 오판**: 기존 `launch.ps1`은 TCP 접속 가능 여부만 확인하고 프로세스를 백그라운드 실행한 뒤 종료했습니다. 실제 브리지 건강 상태는 확인하지 않았습니다.
3. **로그인 선행 조건 불명확**: 브리지 세션 토큰 없이도 로그인 버튼이 노출됐지만 로그인 핸들러에서 연결 재시도를 하지 않았습니다.
4. **실패 이유 노출 부족**: 브리지 실행 실패 로그가 남지 않아 설치 단계의 오류 확인이 어려웠습니다.

## 구현 변경

- Windows `.cmd` 시작부의 구분자 검색 `LastIndexOf` 사용.
- 로컬 브리지 `GET /health` 추가: 설치 도우미가 버전과 서비스 생존 상태를 확인합니다. 계정·세션 토큰은 노출하지 않습니다.
- Windows 설치 후 런처가 응답을 확인하고, 실행 실패 시 `bridge.stderr.log`/`bridge.stdout.log`를 기록하며 오류를 반환합니다.
- 설치 과정은 `%TEMP%\\DramaForge-Setup.log`에 추적 로그를 남깁니다.
- 브라우저 로그인 버튼은 Codex 요청 전에 로컬 브리지에 자동 연결합니다.
- 브리지 연결, Codex 실행, ChatGPT 로그인 상태를 구분해 표시합니다.
- 127.0.0.1에서 네트워크 접속이 거부되면 localhost 경로를 추가로 시도하고 해당 CSP를 허용합니다.
- 작업 데이터는 Vercel 서버에 보관하지 않으며, 기존 Origin 검증과 요청 토큰·허용된 AI 작업 제한을 유지합니다.

## 재배포 및 사용자 확인 절차

1. **v1.7.2 소스를 GitHub 저장소에 반영하고 Vercel에 재배포**합니다. 이 단계 없이는 현재 운영사이트에서 기존 설치 파일이 계속 다운로드됩니다.
2. 브라우저를 새로고침한 후 상단에 `PROJECT WORKSPACE / v1.7.2`가 보이는지 확인합니다.
3. `AI 연결 → 연결 도우미 설치 시작`을 선택해 **새 설치 파일**을 다운로드하고 실행합니다. 첫 실행은 사용자가 직접 허용해야 합니다.
4. 설치 프로그램에서 `설치 완료` 또는 `브리지 정상 실행 확인`을 확인합니다.
5. PC에서 `http://127.0.0.1:7331/health`를 열었을 때 `{"ok":true,"service":"dramaforge-bridge","version":"1.7.2"}`가 보이면 브리지 실행 자체는 성공입니다.
6. 사이트의 `AI 연결`에서 `◉ 브리지 연결` 상태를 확인하고 `ChatGPT 로그인`을 수행합니다.
7. 연결 성공인데 로그인 실패하면 웹 UI의 상태 메시지를 확인하고 `Codex 실행 오류` 여부를 구분합니다.

## 여전히 실패하는 경우

- `%TEMP%\\DramaForge-Setup.log`: 설치 다운로드/무결성/실행 실패 로그
- `%LOCALAPPDATA%\\Programs\\DramaForgeConnector\\logs\\bridge.stderr.log`: 로컬 브리지 실행 오류
- 포트 7331을 기존 버전 또는 다른 프로그램이 점유하고 있다면 **사용 중인 프로그램을 안전하게 종료한 후 재설치**합니다. 알 수 없는 프로세스를 자동 종료하지 않습니다.
- 브라우저가 로컬 네트워크 접속 권한을 요청하면 해당 요청의 출처가 공식 DramaForge 사이트인지 확인하고 결정합니다.

## 검증 범위

- NOT TESTED: Windows PowerShell/EXE 실기기 설치, 사용자 브라우저 실제 네트워크 권한, 실제 ChatGPT 계정 인증, Vercel 운영 반영.

로그에는 비밀 토큰·ChatGPT 비밀번호를 기록하도록 설계하지 않았습니다. 로그를 공유하기 전 개인 식별 정보가 들어 있지 않은지 확인하세요.
